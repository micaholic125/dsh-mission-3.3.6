## 五、`单位名录.csv` 字段

| 列 | 含义 |
|---|---|
| 中文名 | 来自 `unit_names_cn_merged.json` |
| ID | 规则文件里的节名，**改数值只认这个** |
| 类别 | Infantry / Vehicle / Aircraft / Building |
| 造价Cost / 血量Strength / 装甲Armor / 速度Speed / 视野Sight | 单位节数值 |
| 主武器Primary / 副武器Secondary | 指向 `[WeaponTypes]` 的节名 |
| 拥有方Owner | 可建造阵营；**为空 = 谁都造不了（AI 专用）** |
| 科技等级TechLevel | `-1` 通常代表不可建造 |
| 前置建筑Prerequisite | 逗号分隔 |
| 英文名Name | 单位节 `Name=` 值 |
