# 开发日志机制

## 目录约定

```
devlog/
  README.md              # 本文件
  YYYY-MM-DD.md          # 每天一篇，文件名即日期
```

## 每篇必含四段（缺一段即视为未完成）

1. **完成**：今天实际做完的事，附证据（文件路径/命令结果/差异条数）
2. **代办**：明天或下一步要做的事，按优先级排
3. **风险**：已知隐患、未验证的假设、可能回滚的点
4. **下一步**：一句话说明下次开工从哪开始

## 生成方式

- **手动**：`python tools/devlog.py`（自动创建今天这篇并套模板；已存在则不覆盖）
- **自动**：已配置定时任务，每天 23:45 触发一次，补全当天日志（当天无工作则写"无"）

## 内容要求

- 中文短句，结论先行。
- 危险操作（写游戏目录、覆盖文件）必须留 **sha1 + 时间**。
- 引用文件一律带路径，必要时带行号，如 `docs/03-设计规范.md:12`。
- 不写"待定""再看看"这类空话；要么写清楚，要么写进"风险评估"。
